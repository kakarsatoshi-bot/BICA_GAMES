# MOS QUEST 〜ワード・エクセル ぼうけんの書〜

MOS（Word / Excel）の授業向け・試験対策RPGゲームです。
生徒はモンスターとのバトル（選択式クイズ）でレベルを上げ、成績をきそいます。

v2.1 から、MOS と並ぶ対策項目として **IPA 基本情報技術者試験** を準備中です（後述「対策項目」。問題を収録するまでは表示されません）。

**すべて無料で運用できます**（サーバー代・管理費 0円）。

## ゲームの内容

| 要素 | 内容 |
|---|---|
| クエスト | エクセルの塔（6クエスト60問）＋ワードの城（6クエスト60問）＝計120問。MOS 365の公式出題範囲（ブック/文書管理・印刷含む）をカバー |
| かしこい出題 | 各クエストは問題プールから毎回8問を「未挑戦→復習期限→苦手」の優先順で自動選出。周回するほど弱点だけが出題される |
| バトル | 4択問題に正解するとモンスターを倒せる。まちがえるとハートが減る |
| コンボ・かいしん・ひっさつ | 連続正解でこうげきが進化（つるぎ→いなずま→ごうか→ふぶき→りゅうせい）。ときどき「かいしんの いちげき」が出る。正解でたまる「ひっさつゲージ」が満タンになると、次の正解で名前つきの必殺技が出てハートが1つ回復する（ゲージは次の戦闘へ持ちこされる。もぎけんていでは使わない） |
| クイック | 問題が出てから一定の時間内に正解すると「クイック！」の表示と音が出る。**経験値には影響しない**（読む速さでランキングが変わらないようにするため。回数は実績に数えられる）。おそくても罰はなく、出た瞬間の当てずっぽうは数えない。もぎけんていでは出ない |
| むげんの めいきゅう | クエストを3つクリアすると入れる、終わりのないモード。クリア済みクエストの問題が「復習期限→苦手→それ以外」の順で出つづけ、3回ミスすると終わり。ちか何かいまで もぐれるかをきそう。5かいごとにボス（ちか30かいまでは、たおすとハートが1つ回復）。記録は進むたびに保存されるので、とちゅうで閉じても消えない。**復習の期限がまだ来ていない問題に正解しても記憶ボックスは上がらない**（続けて解くだけで「覚えた」ことにならないように。まちがえたときは他のモードと同じくボックス0に戻る） |
| ボス | 各クエストの最後3問はボス戦。全クエスト制覇で「まおうの城」が解放 |
| もぎけんてい | 本試験と同じ1000点満点・合格ライン700点の20問模試（Excel/Word別）。分野別の苦手診断つきで、最高スコアは先生のシートにも記録される |
| 経験値 / レベル / ランク | 正解でEXP獲得。連続正解ボーナスあり。レベルに応じて「みならい冒険者→…→でんせつの勇者」と称号が上がる |
| ふっかつのほこら（復習） | **忘却曲線（間隔反復）** にもとづき、忘れかけたタイミングの問題と、まちがえた問題だけを自動で出題 |
| きおくの地図 | 問題ごとの習熟度（記憶の定着度）を色で見える化 |
| 成績の送信・共有 | 生徒の成績は先生のスプレッドシートに自動送信。クラス全体のランキングは先生がClassroom等で共有（詳しくは後述） |
| バトル背景 | クエストごとに森・洞くつ・城・荒野・塔…と背景が変わる（すべてコード描画のオリジナルドット絵） |
| ご意見箱 | 画面右下の📮からいつでも感想・要望・問題の間違い報告を投稿できる。スプレッドシートの「ご意見箱」シートに届く |
| なまえの変更 | 「ぼうけんのしょ」画面からいつでも名前・クラスを変更できる（成績は引き継がれる） |
| モンスター図鑑 | 遭遇したモンスターに、Excel/Wordの「あるある」ネタの一言バイオが解放される（「ぼうけんのしょ」から） |
| 激レアモンスター | ごく低確率で「コピペマスター」など4種類の激レアが出現するお楽しみ要素（ボーナスEXPつき） |
| 色ちがい・メダル | ごく低確率で色ちがいのモンスターが出現し、たおすと図鑑に登録される。同じモンスターを10・30・100体たおすと図鑑にメダルがつく |
| 実績・ミッション | 実績44種類（条件と進みぐあいが見える。達成したその場で知らせる）、日替わりのミッション3つ、ログインの連続記録。メニューに「つぎの めあて」（あと少しでとれる実績）が出る |
| クエストの習熟度 | クエスト一覧に「しゅうじゅく ○%」が出る（そのクエストの全問の記憶ボックスの合計）。★はクリアのうまさ、こちらは「どれだけ覚えたか」。問題がボックス5に届いた瞬間は「マスターした！」と祝う |
| キーボード操作 | バトル中は 1〜4 で選択肢、Enter／スペースで「すすむ」（教室のPCで手を止めずに進められる） |
| えんしゅつ・音 | 粒・光・画面ゆれなどの演出と、コードで鳴らすオリジナルのBGM・効果音。**「ひかえめ」設定**と**音の3段階切りかえ**つき（後述） |
| 試験日カウントダウン | MOSの試験日を設定すると、メニュー画面に王さま・お姫さま・まおうが残り日数に応じて一言くちを出す |
| エキスパートの隠しダンジョン | まおうの城クリア後にのみ解放される、MOS Excel Expert範囲の追加ダンジョン（5クエスト・裏ボスつき） |
| じっせん道場 | 実際のExcelファイルをダウンロード→操作→アップロードして採点する実技問題。採点は先生のGoogle Apps Script側で行われ、生徒には正解データが一切見えない（設定方法は後述） |

### 記憶定着のしくみ（ライトナー方式）

問題ごとに「記憶ボックス0〜5」を管理しています。

- 正解するとボックスが1つ上がり、次の復習は先になる（1日後→3日後→7日後→14日後→30日後）
- まちがえるとボックス0に戻り、すぐ復習対象になる

エビングハウスの忘却曲線に合わせ「忘れかけたころに再出題」されるため、
定期的に遊ぶだけで記憶が定着します。「ふっかつのほこら」に赤い数字が出ていたら復習どきです。

## えんしゅつ・音の設定

### 生徒が自分で変えられるもの

| 設定 | 場所 | 内容 |
|---|---|---|
| 音 | 画面右下の「♪」ボタン | はじめは「♪ おとだけ」（効果音だけ。これまでと同じ）。押すたびに「♪ おんがく（音楽＋効果音）→ ♪ OFF → ♪ おとだけ」と切りかわる。端末ごとに記憶される。もぎけんていでは音楽は流れない |
| えんしゅつ | タイトル画面の下、または「ぼうけんのしょ」の「せってい」 | 「はで」と「ひかえめ」を切りかえる。**ひかえめ**にすると、画面のゆれ・画面全体の光・くり返す動きが止まり、粒の数も減る |

> ⚠️ **光の点滅が苦手な生徒には「ひかえめ」を案内してください。** 端末の設定で「視差効果を減らす／アニメーションを減らす」が
> オンになっている場合は、（本人がゲーム内で選び直していないかぎり）「ひかえめ」で動きます。画面全体の光は、どちらの設定でも1回ずつ・うすく・ゆっくり消える形にしてあります。

### 先生が変えられるもの（コードの定数）

| 変えたいこと | 場所 |
|---|---|
| 音楽を最初から全員に流す | `js/sound.js` の `BGM_DEFAULT_ON` を `true` にする（既定は `false`＝ボタンを押した人にだけ流れる。教室では1台ずつ別々に曲がくり返すので、全員ヘッドホンでなければ `false` のままがおすすめ） |
| かいしんの確率・ひっさつゲージのたまり方・EXPの倍率 | `js/game.js` の `TUNE` |
| クイック（早押し）に経験値をつける | `js/game.js` の `TUNE.quickXp` など（⚠️ 0 より大きくすると、読むのが速い生徒ほどランキングで有利になる。既定は 0） |
| むげんの めいきゅうに入れる条件・ボスの間隔・回復できる深さ | `js/game.js` の `ENDLESS_UNLOCK`／`ENDLESS_BOSS_EVERY`／`ENDLESS_HEAL_UNTIL` |

> 💡 `js/*.js` や `css/*.css` を更新したときは、`index.html` の `?v=2.3.0` の数字を上げてください
> （生徒の端末に古いファイルが残って、新しい内容が出ないのを防ぐため）。

## MOS単語帳（日本語がまだ苦手な生徒向け）

`vocab` フォルダに、MOS QUESTとは別の単独アプリとして「MOS単語帳」を同梱しています。
日本語を勉強中の外国人生徒が、MOS受験に必要な日本語の専門用語（セル・書式設定・差し込み印刷など）を
**英語訳＋ふりがな**付きで覚えられる、シンプルなフラッシュカード＋クイズアプリです。

- 対応カテゴリー：きょうつう操作／Excel専用／Word専用／復習（まだ覚えていない語だけ）
- フラッシュカードモード：カードをタップでめくって「おぼえた／もう一度」を記録
- クイズモード：4択クイズ（日本語→英語、または「英語→日本語」に切り替え可）
- 学習の記録はブラウザのlocalStorageに保存（成績送信はしません。個人情報のやり取りは一切ありません）
- 単語データは `vocab/js/words.js` にあり、MOS QUESTの問題と同じ書き方（配列に足すだけ）で追加・編集できます

MOS QUESTのタイトル画面から「📘 MOS単語帳」リンクで開けるほか、`vocab/index.html` を直接開いても遊べます。
公開方法はMOS QUESTと同じで、`vocab` フォルダごとGitHub Pages等にアップロードすればそのまま動きます。

> 💡 `vocab/js/*.js` や `vocab/css/*.css` を更新したときは、ブラウザのキャッシュで古いファイルが
> 表示され続けるのを防ぐため、`vocab/index.html` の `?v=2` の数字を1つ増やしてください
> （例: `js/app.js?v=2` → `js/app.js?v=3`）。増やさないと、生徒の端末に前のバージョンが
> キャッシュされたままになり、新機能が反映されないことがあります。

## 公開のしかた（どれか1つでOK）

ゲームは `game` フォルダだけで完結する静的サイトです。ビルドやサーバーは不要です。

> ⚠️ **注意**: この bica-materials リポジトリ自体は公開しないでください（授業の解答ファイルが入っているため）。
> 公開するのは `game` フォルダの中身だけです。

### 方法A: GitHub Pages（おすすめ・無料）

1. GitHubで新しい**公開（Public）リポジトリ**を作る（例: `mos-quest`）
2. `game` フォルダの中身（index.html, css, js）をそのリポジトリにアップロードする
   （GitHubの画面で「Add file → Upload files」にドラッグ＆ドロップでOK）
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に表示されるURL（`https://ユーザー名.github.io/mos-quest/`）を生徒に配る

### 方法B: Netlify Drop（アカウント登録すれば無料・ドラッグ＆ドロップだけ）

1. https://app.netlify.com/drop を開く
2. `game` フォルダをそのままドラッグ＆ドロップ
3. 表示されたURLを生徒に配る

### 方法C: 校内PCで直接開く

`game/index.html` をダブルクリックするだけでも遊べます（成績の送信以外の全機能が動きます）。

## 成績の送信・共有の設定（やらなくてもゲームは動きます）

先生からの進捗確認を有効にする手順です。約10分で終わります。

1. **Googleスプレッドシートを新規作成**（名前は「MOS QUEST 成績」など自由）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から書いてあるコードを全部消して、このリポジトリの
   **`gas/mos_quest_backend.gs`** の中身をぜんぶ貼り付けて保存
   （じっせん道場を使う場合は、この後の手順で左メニューの「サービス」から
   **Drive API**（Advanced Google Services）も追加しておくこと）
4. 右上の **デプロイ → 新しいデプロイ** をクリック
   - 種類の選択（歯車マーク）→ **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - デプロイ → アクセスを承認（自分のGoogleアカウントを選んで許可）
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/...../exec`）をコピー
6. Apps Scriptの「プロジェクトの設定」（左メニューの歯車マーク）→「スクリプト プロパティ」で
   **`API_KEY`** という名前のプロパティを追加し、値には**パスワードのようなランダムな文字列**を設定する
   （例: 大文字小文字と数字を混ぜた20文字程度。誰にも教えないこと）
7. `game/js/config.js` を開いて、次の3か所を書きかえて公開し直す

```javascript
SYNC_URL: "ここにコピーしたURLを貼る",
API_KEY: "手順6で決めたのと まったく同じ文字列",
CLASSES: ["1年A組", "1年B組"],   // 実際のクラス名に書きかえる
```

これで、生徒がゲームをプレイすると自動的にスプレッドシートへ成績が送信されるようになります。

### ランキング（成績一覧）の共有方法

**ゲームのメニューにある「ランキング」画面で、クラス全員のランキング（なまえ・クラス・
レベル・XP・つ星）が一覧表示されます。** 生徒がゲームをプレイするたびに自分の成績を送信し、
ランキング画面を開くたびに全員分の最新の順位を取得して表示します。

⚠️ **これは、他の action（sync/feedback/gradePractical）とは違い、生徒全員のなまえ・クラス・
成績をまとめて読み取れる read API（`getRanking`）です。** ゲームは静的サイトなのでソースコードは
誰でも見え、`API_KEY`（合言葉）も本気で調べれば見つかる可能性があります。つまり、そのキーを
知っている人は誰でも全生徒の一覧を取得できる、という前提で運用してください。実名ではなく
ニックネームで登録させたい場合は、生徒に案内するときに一言添えるとより安全です。

上記のリスクを避けて、Google純正の権限管理（組織内限定・閲覧のみ共有）だけでランキングを
共有したい場合は、ゲーム内表示を使わずに以下の運用にすることもできます。

1. 「Players」シートを開く
2. 右上の「共有」ボタン → 「制限付き」を「〇〇（学校のドメイン名）」に変更
3. 権限は「閲覧者」のままにする（生徒が編集できないように）
4. 発行されたリンクを、Google Classroomの「授業」または「ストリーム」に投稿する

見やすく整えたい場合は、シートをコピーして生徒向けの表示用シート（名前・クラス・レベル・EXPだけを
`QUERY`関数などで抜き出したもの）を作り、そちらを共有するのがおすすめです。

#### ランキングをPDFで発表したいとき

スプレッドシートを開くと上部メニューに **「MOS QUEST」→「ランキングPDFを作成」** が
表示されます（`onOpen()` で自動追加されるので、追加の設定は不要です）。クリックすると、

1. 「Players」シートのデータをレベル→XPの順で並べ替え、
2. 生徒ID等の内部情報を除いた発表用の「ランキング」シートを自動作成し、
3. そのシートだけをA4横向きのPDFとして**マイドライブ直下**に保存します

（初回実行時はDriveへのアクセス許可を求められるので許可してください）。完了すると
保存先のリンクがダイアログで表示されるので、そのままダウンロードしてプロジェクターで
映したり、印刷して掲示したりできます。

### 先生の確認方法

**スプレッドシート（元の「Players」シート）を開くだけ**で、生徒全員のレベル・EXP・正解率・
クエスト達成数・最終プレイ日時が1人1行で見られます（自動更新）。

### ご意見箱

生徒がゲーム内の📮ボタンから送った感想・要望は、同じスプレッドシートに自動作成される
**「ご意見箱」シート**に届きます（受信日時・なまえ・クラス・内容・送った画面）。
こちらも送信専用で、生徒が他の生徒の投稿を読むことはできません。

> 💡 コードを修正して再デプロイするときは「デプロイを管理 → 編集 → 新バージョン」を選んでください（URLが変わりません）。

## じっせん道場（実データ差分採点）の設定（やらなくてもゲームは動きます）

「じっせん道場」は、実際のExcelファイルをダウンロード→操作→アップロードして採点する機能です。
**採点は先生のGoogle Apps Script側でのみ行われ、正解データが生徒に見えることは一切ありません。**
上の「成績の送信・共有の設定」を先に済ませておく必要があります。

### 準備するもの

- 各課題の「正解ファイル」（`.xlsx`）。問題ファイル（`assets/practical/`にあるもの）を実際に
  正しく仕上げたものを、先生ご自身で1つずつ作成してください（生徒に配る問題ファイルは
  リポジトリに含まれていますが、正解ファイルは意図的に含めていません）。

### 設定手順

1. 「成績の送信・共有の設定」の手順3で、Apps Scriptエディタの左メニュー「サービス」（＋アイコン）
   から **Drive API**（Advanced Google Services）を追加する
2. 各課題の正解ファイルを、ご自身のGoogle Driveの好きな場所にアップロードする
3. アップロードしたファイルを開き、URLの中の `.../d/【ここ】/edit` の部分（ファイルID）をコピーする
4. Apps Scriptエディタで `gas/mos_quest_backend.gs` の末尾にある
   `setupAnswerKey_P1()` などの中身（`"ここに正解ファイルのDriveファイルIDを貼る"`の部分）を
   コピーしたIDに書きかえる
5. エディタ上部の関数選択で `setupAnswerKey_P1` を選び、▶実行（初回はDriveへのアクセス許可が必要）
   → `setupAnswerKey_P2`、`setupAnswerKey_P3` も同様に実行する（課題ごとに1回だけでOK）
6. 実行ログ（表示 → ログ）に変換後のファイルIDが出力されていれば設定完了

これで、生徒がじっせん道場でファイルをアップロードすると自動採点され、結果がゲーム内に
表示されるとともに、スプレッドシートに自動作成される「Practical」シートにも記録されます。

新しい課題を追加したい場合は、`js/questions_excel_practical.js` の `PRACTICAL_TASKS` と
`gas/mos_quest_backend.gs` の `PRACTICAL_ANSWER_SPECS`（採点対象セルの一覧）の両方に
同じIDでエントリーを追加し、上記の手順で正解ファイルをセットアップしてください。

## 試験日カウントダウンの設定（やらなくてもゲームは動きます）

MOSの試験日を設定すると、メニュー画面に王さま・お姫さま・まおうが残り日数に応じて
一言くちを出すようになります（GAS側の設定は不要、ゲーム内だけで完結します）。

MOSの試験日はインターネットから自動取得することはできません（学校ごとに個別で
手配される日程のため、外部サイトを機械的に読み取っても正しい日付とは限りません）。
そのため、先生が把握している試験日を `game/js/config.js` の `EXAM_DATES` に
**わかっている分だけリストで**入力する方式にしています。

```javascript
EXAM_DATES: ["2026-09-04", "2026-12-06"],   // "年-月-日" の形式。空配列 [] なら非表示のまま
```

今日から見て一番近い「未来の」日付が自動で選ばれるので、1つの試験日が過ぎたら
リストの次の日付に**自動で切り替わります**（過ぎた日付を消す必要はありません）。
次回の試験日が決まったら、配列に追記して公開し直すだけでOKです。

残り日数が多いうちは王さまがのんびり励まし、直前になるとまおうがスパルタに焦らせてきます。
試験が終わったあとは（リストに次の日付がなければ）王さまが労いの言葉をかけ続けます。

## セキュリティについて（かならずお読みください）

このゲームは「静的サイト＋GAS Web App」というシンプルな構成のため、
**ゲーム側の仕組みだけで完全に外部からの不正アクセスを遮断することはできません**。

**⚠️ ゲーム内ランキング（`getRanking`）は、生徒全員の名前・クラス・レベル・XP等を
まとめて読み取れる read API です。** `API_KEY`（合言葉）を知っている人であれば、
理論上は誰でもこのAPIを呼び出して全生徒の一覧を取得できてしまいます。ゲームは
静的サイトなのでソースコードは誰でも閲覧でき、`API_KEY`も「本気で調べようとする人」を
完全には防げない簡易的な門番です。ランキングを表示しない（あるいはPDF運用のみにとどめる）
場合は、`gas/mos_quest_backend.gs` の `doPost()` から `case "getRanking":` の行を削除すれば、
このAPIごと無効化できます。

このリスクを踏まえ、次の対策をとっています。

1. **本名を送信・表示しない運用にする**：生徒には**本名でなくニックネームでの登録**を
   案内しています（登録画面にも案内文を表示済み）。ランキングに出るのはこのニックネームです。
2. **送信APIそのものは書き込み専用**：`sync`（成績送信）・`feedback`（ご意見箱）・
   `gradePractical`（じっせん道場の採点）は、いずれも自分のデータを送るだけで、
   他人のデータを読み取ることはできません。おかしなデータが登録された場合も、
   スプレッドシートの該当行を削除するだけで消せます。
3. **PDF運用への切り替えも可能**：`getRanking` を無効化しても、スプレッドシート側の
   「MOS QUEST」→「ランキングPDFを作成」メニューは引き続き使えます。よりリスクを抑えたい
   場合はこちらへの切り替えを検討してください。

## 対策項目（MOS・IPA 基本情報技術者）

タイトル →（はじめての人は登録）→ **「たいさく こうもくを えらぶ」** → その項目のメニュー、の順に進みます。
メニュー上部の「たいさく こうもくを かえる」でいつでも切りかえられます。前回えらんだ項目には印がつきます。

| 項目 | 内容 |
|---|---|
| 共通のもの | セーブ（1人1つ）・経験値・レベル・称号・実績・図鑑・ミッション・ログイン記録・ひっさつゲージ |
| 項目ごとのもの | クエスト・ふっかつのほこら（復習）・まおうの城（解放条件と討伐）・むげんの めいきゅうの出題・もぎけんてい・ぼうけんのしょの「クエストたっせい／★／きおくの地図」 |
| MOS だけのもの | エキスパートの おくち・じっせん道場・試験日カウントダウン・MOS単語帳のリンク |

- 定義は `js/courses.js`（科目・もぎけんていの問題数と合格ライン・メニューの並び）。基本情報の模試は1000点中600点で合格（本試験の IRT 採点は再現できないため、結果に「正答率からの めやす」と出ます）。

### IPA 基本情報技術者の問題について（出典のルール）

- 問題は **IPA が公表している公開問題（令和5〜8年度＝2023〜2026年度）だけ**を使います。旧午前問題は使いません。
- **解説はすべて自作**です（IPA は解説を公表していません）。第三者サイトの解説は参照も転記もしません。
- 各問に出典を常に表示します。書式は `出典:令和7年度 基本情報技術者試験 科目A 公開問題 問3`。問題を変えたときは末尾に `(一部改変)` を付けます。
- IPA の問題は**選択肢を並べ替えません**（並べ替えも改変とみなすため）。
- 問題 id は出典から作ります（例 `FE-2025A-03`）。一度公開した id は変更・削除しません。
- いまは IPA の問題ファイル（`js/questions_ipa_fe_a.js`・`js/questions_ipa_fe_b.js`）を `index.html` で読み込んでいないため、**IPA の項目は表示されず、選択画面も出ません**（生徒には今までどおり MOS のメニューが出ます）。問題が1問も無い項目は自動で隠れ、読み込むと選べるようになります（入れ方は下の「IPA の公開問題の入れ方」）。

### 成績シート（GAS）の更新が必要です

1. Apps Script エディタに新しい `gas/mos_quest_backend.gs` の内容を貼りつけて保存
2. 「デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ」（URL は変わりません）

再デプロイしなくてもゲームは動きます（新しい2列が記録されないだけです）。見出しは次の送信時に自動で書き足されます。

## 問題の追加・編集のしかた

問題データは `game/js/questions_excel.js` と `game/js/questions_word.js` にあります。
プログラミングの知識がなくても、次の形をまねして書き足せます。

```javascript
{
  id: "XL2-9",                       // ← 他とかぶらないID。一度公開したら変えない！
  q: "問題文をここに書く",
  c: ["正解の選択肢", "はずれ1", "はずれ2", "はずれ3"],
  a: 0,                              // 正解の位置（0=1番目）。選択肢は自動でシャッフルされます
  exp: "解説をここに書く（まちがえたときに表示され、記憶定着を助けます）"
}
```

- **`id` は変更・使い回し禁止**です。生徒の復習記録（忘却曲線のデータ）がIDに紐づいています。

### IPA の問題で使う項目（任意。MOS の問題は使わないので、今までどおり動きます）

| 項目 | 例 | はたらき |
|---|---|---|
| `fixedOrder` | `true` | 選択肢を並べ替えずに `c` の順で出す（IPA の問題は必ず付ける。1列で表示） |
| `labels` | `"aiue"` | 選択肢に「ア イ ウ エ …」を付ける。まちがえたときの「せいかいは」も記号つき |
| `c` の数 | 4〜10個 | 科目B の「ア〜コ」にも対応。キーボードは 1〜9 |
| `source` | `"令和7年度 基本情報技術者試験 科目A 公開問題 問3"` | 「出典:…」を問題の間も解説の間もずっと表示 |
| `instant` | `true` | タイプライターの演出を飛ばして問題文を一度に出す |
| `passage` | 文字列 | 長文をモンスターの下のスクロール領域に出す |
| `code` | 文字列 | 擬似言語・SQL などを等幅で出す（横にはスクロール） |
| `table` | `[["商品ID","商品名称"],["S001","冷蔵庫"]]` | 表を出す（1行目が見出し） |
| `tableHeader` | `false` | 見出しの行が無い表のとき（1行目も ふつうのセルにする） |
| `tables` | `[{ caption: "表", rows: [[…],[…]] }, { caption: "追加後の表", rows: … }]` | 題名つきの表を複数出す（図のあとに出る）。見出しの行が無い表は `header: false` |
| `figure` / `figureAlt` | `"img/fe/2025r07_a03.png"` | 図の画像を出す（画像は `img/fe/` に置く） |
| `field` | `"データベース"` | シラバスの中分類（クエストの振り分けに使う。画面には出ない） |
| `c` に記号だけ | `["ア","イ","ウ","エ"]` | 図の中の ア〜エ から選ぶ問題（タイミングチャートなど）。ボタンには記号だけが出る（横に並ぶ） |
| `choiceTable` | `{ caption: "解答群", rows: [["","a","b"],["ア","…","…"],…] }` | 解答群が表の問題（科目B の「a と b の組合せ」など）。プログラムのあとに表を出す。`c` は記号だけにする |
| `notation` | `"fe_pseudo"` | 戦闘画面に「ぎじげんごの きじゅつけいしきを みる」ボタンを出す（中身は `js/questions_ipa_fe_b.js` の `FE_NOTATIONS`） |
| クエストの `hearts` | `5` | そのクエストの ♥ の数（科目B の道場は1問が長いので ♥5。書かなければ 3） |

- 問題文・選択肢・表・プログラムは、すべて文字として表示します（HTML としては解釈しません）。
- `fixedOrder` の問題の選択肢は、`\n` の改行をそのまま出します（SQL を複数行で書いた選択肢など）。
- `passage`・`code`・`table`・`tables`・`figure` のある問題では、クイック（早押し）判定を出しません。
- もぎけんていに制限時間を付けるときは、`js/courses.js` の `exams` に `minutes` を書きます（基本情報の科目A は 20問30分。時間切れのときは、答えていない問題を不正解にして結果を出します）。MOS の模試には付けていません。
- 問題を消すときも、できれば残したまま入れ替えを。消すと生徒側の記録は無視されるだけで害はありません。

クエスト（「科目A の まち」「科目B の 道場」）は、はんいに関係なく いつでも別々に入れます。
⚠️ 科目B もぎしけんの最高点は、いまは成績シート（GAS）に送っていません（送るには `gas/mos_quest_backend.gs` に列を足して再デプロイが必要）。

### 生徒に出すときの手順

**まだ `index.html` で読み込んでいません**（読み込むと生徒の画面に IPA の項目が出ます）。生徒に出すときは次の順で。

1. 先生が解説を読み合わせる（各 PR の説明にある「人の確認が必要な問題」の一覧を参照）
2. `index.html` の `<script src="js/courses.js…">` の**前**に `<script src="js/questions_ipa_fe_a.js?v=…"></script>` を1行足し、`?v=` の数字を上げる（科目B も出すときは `js/questions_ipa_fe_b.js` も同じように足す）
3. `node tools/check_questions.mjs` が 0 件であることを確かめる（読み込んだファイルは、クエストの問題数が8未満だとエラーになる）

⚠️ 生徒に出した後は、問題 id（`FE-2025A-03` など）を変えたり消したりしないでください（復習の記録が id に結びついています）。

### 作業用のスクリプト（問題を入れるとき）

| 手順 | コマンド（リポジトリのルートで） | すること |
|---|---|---|
| 1. PDF の取得 | `python3 -I tools/ipa/extract_fe.py fetch 2025` | 問題と解答の PDF を `work/ipa/` に保存（`work/ipa/` はコミットしない） |
| 2. 下書き | `python3 -I tools/ipa/extract_fe.py draft 2025` | `pdftotext` で文字にし、問題文・選択肢・正解（解答 PDF）を `work/ipa/fe_a_draft.json` に書き出す。図・表のある問題には印がつく |
| 3. 図 | `python3 -I tools/ipa/extract_fe.py figures 2025` | スクリプトの `FIGURES` に書いた範囲を `img/fe/` に PNG で切り出す |
| 4. 収録 | （手作業） | 下書きを PDF と見くらべて `js/questions_ipa_fe_a.js` に書く。表は `table`、SQL・プログラムは `code`、図は `figure`。解説は自作 |
| 5. 正解の突き合わせ | `python3 -I tools/ipa/extract_fe.py check 2025` | 収録した `a` が解答 PDF と1問でも違うとエラー。問題文・選択肢が PDF の文字と違う問題も一覧にする |
| 6. 検査 | `node tools/check_questions.mjs` | 下の条件を検査（エラーが1件でもあれば exit 1） |
| 7. 画面で確認 | `node tools/ipa/play_fe.cjs` | Playwright で、全問を実際の画面に出して正解・不正解の両方で解き、はんいの切りかえ・もぎしけんも確かめる（index.html はテストの中でだけ書きかえる） |

科目B は、手順 1〜3・5 に `--subject b` を付けます（例 `python3 -I tools/ipa/extract_fe.py check 2025 --subject b`）。
科目B の `draft` は問題ごとの文字と正解を `work/ipa/fe_b_draft.json` に書き出すだけで、収録は手で組み直します。

`tools/check_questions.mjs` は `js/questions_*.js` をすべて読み、id・選択肢の重複、`a` の範囲、解説の長さ（15文字以上）、
`figure` のファイル、IPA の問題の `source` の書式・`fixedOrder`・`labels`、`choiceTable` と選択肢の数・記号、`notation` の中身、クエストの問題数（8問以上）、
直前のコミットにあった id が消えていないかを調べます。まだ `index.html` で読み込んでいないファイルのクエストの問題数は「注意」として出るだけです。
必要なもの：Python 3（標準ライブラリだけ）、poppler（`pdftotext`・`pdftoppm`）、Node.js。

## よくある質問

**Q. 生徒のデータはどこに保存される？**
A. 生徒それぞれのブラウザ（localStorage）に保存されます。同じPC・同じブラウザで続きから遊べます。
ブラウザを変えたり履歴を全削除するとレベルはリセットされます（スプレッドシート側の記録は残ります）。

**Q. パスワードは？ なりすましが心配**
A. 授業用のカジュアルなゲームなのでパスワードはありません。名前とクラスだけで登録できます。
おかしな名前の登録があったら、スプレッドシートの該当行を削除すれば消えます。

**Q. 費用は本当に0円？**
A. はい。GitHub Pages / Netlify の無料枠、Google Apps Script・スプレッドシートの無料枠だけで動きます。
生徒数百人規模でも無料枠を超えることはまずありません。

**Q. スマホでも遊べる？**
A. 遊べます。画面はスマホ表示に対応しています。

**Q. ドラゴンクエスト等に似すぎていない？**
A. モンスターのデザイン・名前・称号・文言はすべてこのゲームのオリジナルです。
「レトロRPG風」という雰囲気（ジャンル）のみを踏襲し、既存作品の固有の名称・キャラクター・画像・音楽は一切使用していません。
