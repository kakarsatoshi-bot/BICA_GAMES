# Microsoft 知的財産(IP)利用ガイドライン

出典: [Microsoft Trademark and Brand Guidelines / Permissions](https://www.microsoft.com/en-us/legal/intellectualproperty/permissions)

本プロジェクトで Microsoft の製品名・ロゴ・スクリーンショット等を扱う場合、以下のルールを遵守すること。

## 4つの基本要件

1. **正式な製品名を使う** — Windows, Office, Xbox 等、Microsoft のトレードマークガイドラインに沿った正式名称を使用する(略称・改変不可)。
2. **リンクはプレーンテキストで** — 例: 「This way to Microsoft.com」のような単純なテキストリンクにする。
3. **不適切なコンテンツの禁止** — わいせつ・誹謗中傷・名誉毀損等の内容と関連付けない。
4. **クレジット表記** — 「Used with permission from Microsoft」等の許諾表記を付す。

## 製品名・商標

- 製品名は必ず正式名称のフルネームを使用する。
- Microsoft のトレードマーク&ブランドガイドラインに従うこと。

## スクリーンショット

以下の条件を満たせば、広告・ドキュメント・チュートリアル・動画・Webサイトでの使用が可能:

- リサイズ以外の加工・改変をしない
- 部分的なスクリーンショットは避ける(全体を使う)
- 自社UIの中に組み込まない
- サードパーティのコンテンツや、個人を特定できる情報を含めない

**禁止事項:**
- 起動画面・スプラッシュ画面のスクリーンショット
- ベータ版製品のスクリーンショット

## ロゴ・アイコン

- **ロゴ**: Microsoft のトレードマーク&ブランドガイドラインに準拠する場合のみ使用可
- **製品アイコン**: トレーニング資料・製品に関するドキュメントに限定。広告、衣料品、オンラインコンテンツ、ソフトウェア、TV、動画には使用不可
- アイコンの改変は禁止。Microsoft ソフトウェアの実際の見た目と一致させること

## 禁止されている使用方法

- Microsoft のスポンサーシップ・支持(エンドースメント)を示唆しない
- 許可なく製品のサウンド・アニメーション・画像を使用しない
- 音声/動画ファイル(.wav, .mid, .avi 等)を単体で再配布しない

## 特殊なコンテンツカテゴリ

- **パッケージ画像(Box shots)**: 広告・教育用途で使用可。ただし自社ブランドがより大きく表示されること
- **フォント**: 原則として改変・再配布不可
- **地図**: 商用利用には Bing Maps のライセンスが必要
- **プレス画像**: Microsoft News Center からの編集(報道)目的の利用に限る

## 本プロジェクトでの適用方針

- Microsoft 製品(Windows, Xbox, Office 等)に言及する際は正式名称を使用する
- スクリーンショットを使う場合は上記の禁止事項(部分利用・自社UI組み込み・起動/スプラッシュ画面・ベータ版)に抵触しないか確認する
- ロゴ・アイコンを掲載する前に、トレードマーク&ブランドガイドラインへの準拠を確認する
- Microsoft の支持・提携を示唆する表現(公式パートナー等と誤解される文言)を避ける
- 疑義がある場合は実装前に本ドキュメントを参照し、必要なら Microsoft の許諾窓口に確認する
